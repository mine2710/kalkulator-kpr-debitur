# Konteks Bersama (Antigravity ↔ Claude Code)

Proyek ini dikerjakan bergantian oleh Antigravity dan Claude Code. Agar pemahamannya sama:

1. **Sebelum mulai bekerja, baca `AGENTS.md` di root repo** dan ikuti semua aturannya
   (bahasa Indonesia, jangan tulis token/path lokal ke repo public, warna `bri`/`bri-2`/`bri-sky`, dll.).
2. Untuk detail rumus dan alur data, baca `handoff.md`.
3. Setelah menyelesaikan pekerjaan berarti, **tambahkan satu baris di bagian "Log Keputusan" pada `AGENTS.md`**
   dengan format: `YYYY-MM-DD — Antigravity — ringkasan`.
4. Jangan mengubah "Keputusan yang sudah disepakati" di `AGENTS.md` tanpa bertanya ke pengguna.
